# Property inspection checklist (move-in and move-out)

Basis: the tenant returns the property in the condition in which it was received, except for normal wear and tear (Law 8.245/1991, art. 23, III). The landlord must provide a description of the property's condition if the tenant asks (art. 22, V).

- [ ] Taps (open them, check for leaks and pressure)
- [ ] Drains and traps (drainage)
